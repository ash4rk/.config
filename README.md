# .config

## Setup

``` sh
git clone --recursive git@github.com:ash4rk/.config.git ~/my_config
```

Link all new files from *dot_files* into *~/*:
``` sh
cd ~/.my_config
stow dot_files
```

Fix Doom Emacs icons:

``` sh
M-x nerd-icons-install-fonts
```
